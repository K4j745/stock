# Stock Terminal Dashboard

Static dashboard for GitHub Pages displaying multi-model trading signals,
interactive price charts, and multi-portfolio backtests. All data is
pre-generated by `dashboard/generate.py` and served as static JSON/CSV.

## Enable GitHub Pages

1. Repository **Settings** → **Pages**
2. **Source**: *Deploy from a branch*
3. Branch: `main` (or default), folder: `/docs`

Site URL: `https://<user>.github.io/<repo>/`

## Data updates

The workflow `.github/workflows/dashboard.yml`:
- Schedule: Mon-Fri 17:00 UTC (after US market close)
- Manual: Actions → *Update Dashboard Data* → *Run workflow*

Local generation:

```bash
pip install -r dashboard/requirements.txt
python dashboard/generate.py
```

## Pages

- **Home** (`index.html`) — overview, KPI strip, latest signal per ticker for the selected model, portfolio strip.
- **Prices** (`prices/`) — interactive candlestick + indicators.
- **Charts** (`charts/`) — ML pipeline plots if available (SHAP, feature importance, ROC, …).
- **Signals** (`signals/`) — full multi-model signals panel: filters, agreement matrix, latest-per-pair view, downloadable CSVs.
- **Portfolios** (`portfolio/`) — per-portfolio detail (equity curve, transactions, positions, trade metrics) and side-by-side compare.

## Data layout (`docs/data/`)

```
meta.json                       generation metadata (git commit, schema, data version)
last_updated.json               legacy timestamp file
tickers.json                    legacy flat list of symbols
signals.json                    legacy flat latest technical signal per ticker

registry/
  tickers.json                  authoritative ticker list (symbol, name, sector)
  models.json                   authoritative model list (name, family, description)
  benchmark.json                {"benchmark": "SPY"}

tickers/<TICKER>/
  ohlcv.json                    OHLCV + indicators
  signals.json                  signals grouped by model for this ticker

signals/
  history.json                  every signal record (rich schema)
  latest.json                   latest signal per (ticker, model)
  by_ticker/<TICKER>.json
  by_model/<MODEL>.json

models/
  index.json
  <MODEL>/summary.json          n_signals + classification metrics overall/per-ticker

portfolios/
  index.json                    one row per portfolio with headline KPIs
  <PORTFOLIO_ID>/
    summary.json                portfolio meta + metrics + benchmark metrics
    transactions.json           rich transaction records (audit trail)
    decisions.json              full decision stream (HOLDs included)
    equity_curve.json           daily portfolio value + drawdown
    positions.json              final open positions
    metrics.json                performance + trade metrics
    trades.csv                  same as transactions.json, CSV for pandas/Excel

exports/
  all_signals.csv               every signal as a flat CSV
  all_transactions.csv          every transaction across all portfolios
  portfolio_metrics.csv         one row per portfolio with all metrics
  model_metrics.csv             one row per model with classification metrics
```

## How to add / change things

* **New portfolio** → add a block under `portfolios` in `dashboard/config.json`.
* **New ticker** → add it to the `tickers` array. Then reference it from any portfolio.
* **New model** → add the name to `ml_signals.models` (and either drop trained
  artifacts into `stock_ml/models/saved/` or rely on the deterministic proxy
  defined in `dashboard/lib/signals.py`).
* **New signal source** → register a generator in `dashboard/lib/signals.py`
  and add it to the signal-resolution code in `dashboard/generate.py`.
