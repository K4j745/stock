1 O projekcie

Praca została wykonana w ramach pracy inżynierskiej pt. „Prognozowanie krótkoterminowych zmian cen akcji giełdowych z wykorzystaniem metod uczenia maszynowego oraz symulacja strategii inwestycyjnej” na Uniwersytecie Przyrodniczym w Poznaniu. Autor: Kajetan Kaczyński.

Stock4caster to statyczny serwis prezentujący wyniki pipeline'u uczenia maszynowego, który dla wybranego uniwersum spółek generuje dzienne sygnały decyzyjne BUY / SELL. Serwis nie posiada back-endu ani bazy danych — wszystkie dane są wyliczane offline i publikowane jako statyczne pliki JSON na GitHub Pages.

Szczegółowy opis metodyki, doboru spółek, cech i walidacji czasowej znajduje się na podstronie Instrukcja.

1 About the project

This work was carried out as part of the engineering thesis “Forecasting short-term stock price changes using machine learning methods and investment strategy simulation” at Poznań University of Life Sciences. Author: Kajetan Kaczyński.

Stock4caster is a static site presenting the results of a machine-learning pipeline that produces daily BUY / SELL decisions for a selected universe of companies. The site has no back-end and no database — everything is computed offline and published as static JSON files on GitHub Pages.

A detailed description of the methodology, ticker selection, features and temporal validation is available on the Instructions page.
